## 📝 Core
### 1. `if __name__ == '__main__':` —— 身份核实

这是 Python 的一个内置机制，用来区分**脚本是被直接运行**的，还是**被作为模块导入**到其他文件里的。

- **`__name__` 是什么？** 每个 Python 文件（模块）都有一个内置属性叫 `__name__`。
    
    - 如果你**直接运行**这个文件（比如 `python script.py`），Python 会自动把 `__name__` 赋值为 `'__main__'`。
        
    - 如果你是在另一个文件里 **`import script`**，那么 `script.py` 里的 `__name__` 就会变成 `'script'`（文件名）。
        
- **为什么要这么写？** 为了防止“意外执行”。
    
    > **打个比方：** 你写了一个带有“测试功能”的工具包。如果没有这句话，别人只想借用你工具包里的一个函数，结果一 `import`，你包里的测试代码全跑了一遍。加上这句话，就像装了门禁，只有当你直接运行这个文件时，主程序才会启动。
    

---

### 2. `sys.exit(main())` —— 优雅谢幕

这一行负责启动主逻辑并向操作系统“交卷”。

- **`main()`**： 通常我们会把脚本的核心逻辑写在一个叫 `main()` 的函数里。直接调用 `main()` 就能运行程序。
    
- **`sys.exit(...)`**： 这是关键点。`sys.exit()` 函数会退出程序，并返回一个**退出状态码（Exit Code）**。
    
    - 如果 `main()` 运行成功并返回 `0`（或没有返回值，默认也是 None/0），系统就知道程序正常结束了。
        
    - 如果返回非零数值（如 `1`），系统就知道程序出错了。
        
- **为什么要连着写？** 这在编写命令行工具或需要被其他程序调用的脚本时非常重要。外部的 Shell 脚本或自动化工具可以通过这个状态码来判断你的 Python 程序是否执行成功。
