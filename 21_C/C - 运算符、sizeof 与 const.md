> [!abstract] 摘要
> 本笔记集中说明 C 表达式中常用的算术、逻辑和按位运算符，以及 `sizeof` 和 `const` 的基本语义。

## 运算符

### 算术运算符

```c
++a; // 先递增，再参与当前表达式
a++; // 先使用当前值，再递增
```

常见算术运算符包括 `+`、`-`、`*`、`/` 和 `%`。整数除法会舍弃小数部分；求模运算 `%` 只适用于整数类型。

自增和自减表达式不要在同一条语句中多次修改同一个对象。相比追求简短，拆成多条语句通常更容易阅读和调试。

### 逻辑运算符

```c
if (ready && count > 0) {
    process();
}
```

- `&&`：逻辑与，左侧为假时不会计算右侧。
- `||`：逻辑或，左侧为真时不会计算右侧。
- `!`：逻辑非。

`&&` 和 `||` 的短路规则常用于先检查指针或边界，再访问对象：

```c
if (buffer != NULL && index < length) {
    value = buffer[index];
}
```

### 按位运算符

```c
uint32_t flags = 0;
flags |=  (1u << 3);  // 设置 bit 3
flags &= ~(1u << 3);  // 清除 bit 3
bool set = (flags & (1u << 3)) != 0;
```

- `&`、`|`、`^`：按位与、或、异或。
- `~`：按位取反。
- `<<`、`>>`：左移和右移。

位操作经常用于寄存器、状态标志和协议字段。移位前应确认操作数宽度与符号属性，优先使用 `uint32_t` 等固定宽度无符号类型；类型基础见 [[C - 数据类型与变量]]。

## `sizeof`

`sizeof` 返回对象或类型占用的字节数，结果类型是 `size_t`：

```c
int values[10];

printf("%zu\n", sizeof(int));
printf("%zu\n", sizeof(values));
printf("%zu\n", sizeof(values) / sizeof(values[0]));
```

数组仍处于数组类型时，可以用 `sizeof(array) / sizeof(array[0])` 计算元素数量；数组作为函数参数时会退化为指针，此方法不再成立。数组与指针的关系可继续阅读 [[C - 数组]] 和 [[C - 指针]]。

## `const`

`const` 表示程序不应通过当前表达式修改对象：

```c
void print_array(const int values[], size_t count)
{
    for (size_t i = 0; i < count; ++i) {
        printf("%d\n", values[i]);
    }
}
```

它有两个主要作用：

- 表达接口意图，明确函数只读取传入数据。
- 让编译器阻止意外写入。

对指针而言，需要区分“指向常量的指针”和“常量指针”：

```c
const int *p;        // 不能通过 p 修改所指对象
int *const p2 = &x;  // p2 自身不能改指向
```

更完整的指针组合与内存访问规则见 [[C - 指针]]。
