# 1. 基础 Markdown 语法

### 标题

```
# H1
## H2
### H3
#### H4
##### H5
###### H6
```

# H1
## H2
### H3
#### H4
##### H5
###### H6


### 粗体与斜体

```
*斜体*
_斜体_
**粗体**
__粗体__
***粗斜体***
___粗斜体___
```

*斜体*
_斜体_
**粗体**
__粗体__
***粗斜体***
___粗斜体___

### 删除线

```
~~删除线~~
```

~~删除线~~

### 高亮（Obsidian 扩展）

```
==高亮文字==
```

==高亮文字==

### 引用

```
> 引用内容
>> 嵌套引用
```

> 引用内容
>> 嵌套引用

### 无序列表

```
- 项目1
- 项目2
  - 子项目
* 也可以用星号
+ 或用加号
```

- 项目1
- 项目2

* 也可以用星号
+ 或用加号

### 有序列表

```

```

## 2. Obsidian 特有语法

### 内部链接

```
[[笔记名称]]
[[笔记名称|显示别名]]
[[笔记名称#标题]]
[[笔记名称#^块ID]]
[[笔记名称#^块ID|别名]]
```

[[笔记名称]]
[[笔记名称|显示别名]]
[[笔记名称#标题]]
[[笔记名称#^块ID]]
[[笔记名称#^块ID|别名]]

### 嵌入内容

```
![[笔记名称]]
![[笔记名称#标题]]
![[笔记名称#^块ID]]
![[图片.png]]
![[PDF.pdf]]
```

### 标签

```
#标签
#项目/子标签
```

#标签
#项目/子标签

### 属性（YAML Front Matter）

```
---
title: 笔记标题
tags: [tag1, tag2]

aliases: [别名1, 别名2]

---
```

### 块引用与块ID

```
段落末尾添加 ^唯一ID

[[笔记#^唯一ID]] 引用该块
```

段落末尾添加 ^唯一ID

### 反向链接与图谱

```
- 点击笔记右侧的反向链接面板
- 使用 `[[` 创建链接后自动出现在图谱中
```

### 大纲（Outline）

```
- 使用 Ctrl/Cmd + O 打开大纲视图
- 基于标题自动生成
```
