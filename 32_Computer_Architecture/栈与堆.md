> [!abstract] 核心结论
> 栈用于自动管理函数调用上下文，堆用于运行时动态分配。两者用途和生命周期不同，不应把“堆栈”当作一个含义模糊的整体。

## 栈

栈遵循后进先出（LIFO）。它通常保存：

- 函数局部变量与部分参数；
- 函数返回地址；
- 调用前需要保存的寄存器；
- 每次函数调用对应的栈帧。

栈空间由编译器生成的代码和处理器指令自动维护。函数进入时创建栈帧，返回时释放，不需要手动调用 `malloc()` 或 `free()`。

## 堆

堆用于动态内存分配。在 C 中通常通过 `malloc()`、`calloc()`、`realloc()` 获取空间，并用 `free()` 释放。它的生命周期由程序控制，因此需要防止：

- 内存泄漏；
- 重复释放；
- 释放后继续访问；
- 越界读写。

相关接口参见 [[C 标准库 - stdlib.h]]。

## 栈指针与生长方向

栈指针（Stack Pointer，SP）指向当前栈顶。x86、ARM、RISC-V 等常见体系结构通常采用向低地址生长的栈：

```text
高地址
┌──────────────┐
│ 栈起始边界    │
├──────────────┤
│ 已使用栈空间   │  ← PUSH 或分配栈帧后，SP 数值减小
├──────────────┤
│      SP      │
└──────────────┘
低地址
```

栈的生长约定与处理器体系结构和调用约定有关；链接脚本负责为嵌入式程序预留栈的地址范围，参见 [[链接脚本 - 核心概念]]。
